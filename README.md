# Gibbs Page

Landing page built with Nuxt 4 and Nuxt UI. Includes sections: Hero, Navigation, Live Payouts, How You Learn, SimFi Experience, Built For Performance, Account Selection, Rules & Payouts, Certification Path, FAQ, Ready To Start, Footer.

## Requirements

- Node.js 18+
- pnpm

## Setup

```bash
pnpm install
```

## Development

```bash
pnpm dev
```

Opens at `http://localhost:3000`.

## Build

```bash
pnpm build
```

## Preview production build

```bash
pnpm preview
```

## Lint

```bash
pnpm lint
```
